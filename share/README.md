# listen.hellodemo.app

Opens *[demo] share links (`listen.hellodemo.app/<id>`) with a proper preview in Messages, WhatsApp and
Messenger. Deployed on Vercel with this folder as the project's root directory; there is no build step.

- `api/s.js` looks the song up, fills in the preview tags and returns the viewer with the song inside.
- `api/_viewer.js` is generated by `scripts/build-share-viewer.py` (run by `scripts/stamp-version.sh`).
- `vercel.json` sends `/<10-character id>` to the function and `/` to hellodemo.app.
